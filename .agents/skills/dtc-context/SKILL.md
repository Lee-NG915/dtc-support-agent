# 项目上下文

先读根 [AGENTS.md](../../../AGENTS.md)、[项目档案](../../../.dtc/target-profile.md) 与 [项目方案](../../../docs/project-plan.md) 的适用部分。恢复任务时只补充下一步所需证据，不重载全部教程。

- 本产品首期服务企业内部客服与审批人，查询、草稿、审批、创建工单是主线；新增消费者自动回复入口属于范围变化。
- 查当前分支、upstream、未提交改动及相关 Issue；不把他人的改动计入本轮，不重置共享工作区。已有有效授权与决定沿用。
- 从实际代码、配置和帮助核对命令；项目档案中“已配置”不等于本轮执行成功。未知项写明如何核实。
- 只为当前任务读取资料：文档任务不需要模型密钥或启动数据库；接口任务不需要 Figma；纯本地检查不推断部署完成。
- 本目录是开发助手技能；`app/skills/` 是应用运行时的业务工具配置，两者不可混装。

输出简短上下文：目标/非目标、已有/计划能力、相关源码和权威文档、基线/工作区、验证范围、未知项与下一步。它是任务输入，不扩展外部写入权限。

按根 AGENTS 的路由进入当前阶段；涉及新建或实质修改文档时使用 [文档规范](../dtc-documentation/SKILL.md)。
