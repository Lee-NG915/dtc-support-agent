# 证据记录

遵循 [文档目录与状态规范](../../../docs/guides/documentation.md)。每个主题复用一个稳定记录；设计写当前规则，指南写操作方法，记录写实际发生的事。不要把同一次通过数复制到多篇文档。

事件记录日期、候选提交及工作区、范围、命令与退出状态、结果、失败/未验证项、证据位置和下一步。只在实际有价值时记录详细版本；不能从当前文件倒推历史测试。

设计建议、用户确认、代码实现、本地验证、远端回读、真实试用和生产部署分开。后续通过追加记录，不覆盖旧失败。回读一致只证明内容传输一致。

Git 保存精简结论和可复算的合成样例。原始日志、模型响应和客户数据默认留在忽略目录或受控产物；必要时登记位置、内容哈希、保留期及取回方式。哈希不是脱敏或备份；原始证据不存在就写不可取得，不声称可复算。

恢复摘要置于原记录顶部：当前范围、有效决定、源码与证据、已完成/待验证、阻塞及下一动作。来源报告保留原作者和测量条件，不作为本 fork 的新指标。
